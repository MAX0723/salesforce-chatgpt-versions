# Salesforce ChatGPT Versions

A version-controlled archive for finalized Salesforce development work created with ChatGPT.

## Scope
- Apex classes, triggers, and tests
- Lightning Web Components (LWC)
- Salesforce metadata and configuration notes
- SOQL queries, validation rules, and Flow documentation

## Guidelines
- Commit finalized changes with descriptive messages.
- Update existing files rather than creating duplicate revision files.
- Never commit credentials, tokens, passwords, customer data, or confidential employer code without authorization.
- Keep this repository private when it contains non-public or work-related code.

## Salesforce source layout
Use Salesforce DX paths when practical, for example:
- `force-app/main/default/classes/`
- `force-app/main/default/triggers/`
- `force-app/main/default/lwc/`
- `force-app/main/default/objects/`
